# Human Firewall — Social Engineering Awareness Website

Responsive educational website about social engineering attacks and major security incidents.

## Features
- Infographic poster embedded in the homepage
- Phishing, pretexting, and baiting explainers
- Attack flow, real-world case studies, and prevention strategies
- Comparison table and interactive knowledge-check quiz
- Reference links to CISA, FTC, U.S. DOJ, Target, and Meta
- Responsive design; no framework, backend, or build step

## Run locally
Open `index.html` in a browser. Keep `infographic.png` in the same folder.

## Publish with GitHub Pages
1. Create a repository on GitHub.
2. Upload `index.html`, `infographic.png`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch `main` and folder `/(root)`, then save.
6. Wait for the website URL to appear in Pages settings.
